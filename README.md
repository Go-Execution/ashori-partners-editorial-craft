# Ashori Partners LLC | Editorial Craft Concept

Swiss architectural monograph concept for **Ashori Partners LLC** (Greater Boston, MA), pairing `Cormorant Garamond` display typography with hairline stone grids, sticky trade chapters, toggleable dossier/gallery project views, and heritage pine accents.

## Local Development

```bash
npm install
npm run dev
```

## Build & Lint

```bash
npm run lint
npm run build
```
